## Repository- und Dokumentationsanforderungen

- Dieses Repository dient als öffentliches Lernportfolio zur Vorbereitung auf AI-300.
- Inhalte sollen nachvollziehbar, strukturiert und ohne private Projektdaten dokumentiert werden.
- Labs und Architekturentscheidungen sollen als Markdown dokumentiert werden.
- Relative Links zwischen Dokumenten sollen die Navigation erleichtern.

## Security und Secrets

- Keine Secrets, Tokens, Tenant IDs, Subscription IDs, Client Secrets oder produktiven Zugangsdaten in diesem Repository speichern.
- Keine privaten Hostnamen, privaten Repository-Links oder echten Zugangsdaten dokumentieren.
- Sensible Werte durch Platzhalter wie `<TODO: value>` ersetzen.
